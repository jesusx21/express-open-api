# Express OpenAPI (TypeScript)

A TypeScript-based OpenAPI validator for Express.

This project is a TypeScript conversion of the original [express-open-api](https://github.dev/abiee/express-open-api) by [@abiee](https://github.com/abiee). All credit for the original logic and implementation goes to them—this fork simply adds type safety and better development experience through TypeScript.

> Fully compatible with the original API—just rewritten in TypeScript for improved type safety and developer experience.
